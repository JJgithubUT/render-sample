Flujo de despliegue

  1. git push a main
  2. GitHub Actions ejecuta pruebas y build
  3. Render detecta el commit y corre npm test && npm run build
  4. Si pasa, arranca npm start y verifica /health
  5. Si algo falla, la versión anterior sigue en línea
